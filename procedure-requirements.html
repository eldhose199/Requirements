Procedure Requirements – Test Configuration

This is a separate configuration file. The main OT Manager reads the JSON data below and displays matching requirements only in the Upcoming Surgeries tab.

How to add a procedure later

Add another object inside the JSON array below. Keep keywords short enough to match common variations of the procedure name.

{
  "id": "acl-reconstruction",
  "name": "ACL Reconstruction",
  "keywords": ["acl", "acl reconstruction"],
  "requirements": ["Scopy tower", "Shaver", "ACL jig"],
  "instructions": ["Confirm tower availability", "Check shaver and jig"]
}
